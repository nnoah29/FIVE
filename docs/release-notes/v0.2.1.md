FIVE can now be your system file chooser, and turning it on takes one click.

## What's new

- **System file chooser**: the "Open", "Select folder" and "Save as" dialogs of your browser and other applications can open FIVE's own simple window. It lists folders and files, has an editable path, your usual and pinned folders, file type filters, a name field with an overwrite confirmation, and the same preview panel as the main window (images, PDF, video, audio, archives, text).
- **One-click activation**: Settings, System, "System file chooser" (or `five-gtk --enable-chooser`; `--disable-chooser` goes back, `--chooser-status` checks). A package cannot change your personal portal settings for you, so this is a choice you make once. The default dialog stays as a fallback.
- `five-gtk --chooser open|folder|save` opens the same window on its own and prints the chosen paths.
- Packages install the portal files and recommend `poppler-utils` (PDF previews). The tarball installer fixes the service path for `~/.local` installs.

## Install

Requires GTK 4.16+ and Pango 1.56+ (Arch, Debian 13+, Ubuntu 25.04+, Fedora 42+).

- Arch Linux: `sudo pacman -U five-0.2.1-1-x86_64.pkg.tar.zst`
- Debian / Ubuntu: `sudo apt install ./five_0.2.1_amd64.deb`
- Fedora: `sudo dnf install ./five-0.2.1-1.fc42.x86_64.rpm`
- Other distributions: extract `five-0.2.1-linux-x86_64.tar.gz` and run `install.sh`.

Verify downloads with `sha256sum -c SHA256SUMS`.

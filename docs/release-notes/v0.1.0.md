First public release of FIVE, a fast native file manager for Linux (Rust + GTK 4).

## Highlights

- Folder cards, list and grid views, previews, quick look, disk usage, duplicate finder.
- Pinned folders in the sidebar and a bottom bar of pinned folders and files.
- Zip and unzip, bulk rename, transfer queue.
- Automation rules with trial-first runs, journal and undo.

## Install

Requires GTK 4.16+ and Pango 1.56+ (Arch, Debian 13+, Ubuntu 25.04+, Fedora 42+).

- Arch Linux: `sudo pacman -U five-0.1.0-1-x86_64.pkg.tar.zst`
- Debian / Ubuntu: `sudo apt install ./five_0.1.0_amd64.deb`
- Fedora: `sudo dnf install ./five-0.1.0-1.fc42.x86_64.rpm`
- Other distributions: extract `five-0.1.0-linux-x86_64.tar.gz` and run `install.sh`.

Verify downloads with `sha256sum -c SHA256SUMS`.
